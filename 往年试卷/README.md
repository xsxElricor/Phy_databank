# 往年试卷

这里整理本人收集和录入的物理相关课程往年试卷与复习资料，按课程分目录存放。

## 目录结构

```
往年试卷/
├── 课程名称/
│   ├── 20XX-20XX 期末试卷.pdf
│   ├── 20XX-20XX 期中试卷.pdf
│   ├── 参考答案与提示/
│   └── 复习提纲/
└── README.md
```

## 收录说明

- 每门课程一个目录，试卷按「年份 + 考试类型」命名，例如 `2024-2025 期末试卷.pdf`
- 有答案或解析的，放在同目录的 `参考答案与提示/` 下，文件名与试卷对应
- 自己整理的知识点提纲、题型总结放在 `复习提纲/` 下
- 扫描版试卷优先使用 PDF，多页图片会合并为单个 PDF
