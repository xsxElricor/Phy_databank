# 近代物理实验

中山大学近代物理实验（2025）实验报告、原始数据与处理结果。

每个实验目录下均有 LaTeX 源文件（`.tex`）、参考文献（`ref.bib`）、完整报告（`.pdf`）与原始扫描件（`*scan.pdf`），可直接用 `xelatex` 编译。

| 实验 | 包含内容 |
| --- | --- |
| [光泵磁共振](./光泵磁共振) | LaTeX 报告、共振图像、数据拟合方法 |
| [塞曼效应](./塞曼效应) | LaTeX 报告、磁场标定与分裂测量数据、CCD 谱线图 |
| [声光效应](./声光效应) | LaTeX 报告、示波器实测波形图 |
| [核磁共振稳态吸收](./核磁共振稳态吸收) | LaTeX 报告、共振波形图，`data/`、`data2/` 为原始示波器数据 |
| [气体放电](./气体放电) | LaTeX 报告、两周测量数据 |
| [激光拉曼](./激光拉曼) | LaTeX 报告、405/532 nm 激发下的 CCl₄ 与酒精光谱数据、Origin 工程 |
| [电光调制](./电光调制) | LaTeX 报告、调制曲线与干涉图样 |
| [电子自旋](./电子自旋) | LaTeX 报告、共振信号与拟合曲线 |

> 说明：报告中的插图均放在各实验目录内（塞曼效应、声光效应的原始示波器截图保留在子目录中，已在 `.tex` 里用 `\graphicspath` 指向）。课程讲义与分组/选课表不在此仓库；数据压缩包已解压，不再重复保留。
